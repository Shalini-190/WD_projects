# Web Development Projects Portfolio

A collection of web development projects built using HTML, CSS, and JavaScript. This repository showcases foundational front-end development skills including responsive design, DOM manipulation, and interactive web applications.

## Projects

### Module 2 Projects
A series of web development exercises and projects covering:
- HTML5 semantic markup
- CSS3 styling, layouts, and animations
- JavaScript ES6+ features
- DOM manipulation and event handling
- Responsive design principles
- Form validation
- Interactive UI components

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)

## Getting Started

Clone the repository and open any HTML file in your browser:

```bash
git clone https://github.com/Shalini-190/WD_projects.git
cd WD_projects
```

Open `html/index.html` or browse individual project files.
